# Changelog

## 0.1.0 — 2026-10-14

Initial release: weighted increasing/decreasing L2 PAVA, L1/quantile fits and finite pointwise bounds; stable duplicate-aware coordinate models; interpolation/boundary policies and plateau-aware inverse; versioned JSON and numeric TSV; residual/block explanations, probability reliability, explicit holdout and out-of-fold evaluation; empirical quantile bands and caller-controlled resampling sensitivity.

Includes independent finite optimality oracles, public API tests and three executable integration examples. No general QP, DAG regression, statistical confidence guarantee or performance-parity claim is included.
